# Guia de uso

Esta guia resume el flujo recomendado para investigar una estrategia sin tocar codigo constantemente.

1. Abrir `Home / Overview` y revisar el estado general.
2. Ir a `Data Manager`, descargar o cargar datos y mirar el Data Quality Score.
3. Ir a `Nuevo experimento guiado` o `Backtest Runner`.
4. Elegir un Research Preset segun el objetivo del test.
5. Seleccionar estrategia, parametros, capital, costos y risk settings.
6. Correr el backtest guardandolo como experimento.
7. Revisar `Results Dashboard`: primero diagnostico, despues equity/drawdown.
8. Correr `Robustness Lab` y `Stress Tests` desde el experimento.
9. Completar el Journal con hipotesis, conclusion y proximo test.
10. Exportar el reporte HTML desde `Reports / Export`.

Regla practica: no mires solo retorno. Mira benchmark, drawdown, cantidad de trades, costos, robustez, stress y calidad de datos.
